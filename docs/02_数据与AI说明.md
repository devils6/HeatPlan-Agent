# HeatPlan Agent：数据与AI说明

版本日期：2026-10-19

## 项目关注的问题

HeatPlan关注户外极端高温对人的热应激风险，以及城市规划管理如何识别重点道路、比较空间改善方向。UTCI（通用热气候指数）综合气温、空气湿度、风速和平均辐射温度等因素，用于表征极端高温周模拟条件下行人尺度的热应激水平；研究空间为北京五环内道路。

## 数据来源与生产

HeatPlan的核心研究数据由项目负责人及团队自主开展三维城市建模、建筑与树冠形态计算、行人热环境物理模拟和机器学习分析形成，来自团队已发表的城市热环境研究。

| 数据内容 | 规模与生产方式 | 在HeatPlan中的用途 |
|---|---|---|
| 行人热应激数据 | 545,374个有效道路分析位置；来自团队自主完成的极端高温周行人热环境研究计算 | 表达户外行人热应激空间分布，识别重点道路与问题类型 |
| 建筑与树冠形态数据 | 与分析位置关联的八项三维形态指标，由团队城市形态数据计算形成 | 诊断道路空间特征，比较规划和管理方向 |
| 道路及行政区空间数据 | 关联35,423个道路街段和7个研究行政区，通过点位编号、道路编号与几何关系完成空间关联 | 显示连续道路网络、搜索中文道路名称、定位分析位置 |
| 论文研究证据 | 团队已发表论文中的模型结果、SHAP分析和研究结论，整理为可检索的证据条目 | 支持形态解释和规划管理方向比较 |

核心UTCI结果及建筑、树冠形态指标是团队通过大规模城市建模、物理模拟和后续分析自主完成的研究成果。道路名称与空间几何用于将研究分析位置关联到具体道路，并支持城市规划管理中的地图定位和检索。地图底图使用CARTO与OpenStreetMap服务，并在页面中标注来源。

## 研究范围与形态指标

系统覆盖北京五环内7个行政区，包含545,374个有效分析位置及其对应的道路街段。研究情景为极端高温周模拟。

每个分析位置关联八项10米缓冲区形态指标：

- 树冠指标：覆盖率、平均高度、高度方差、体积。
- 建筑指标：覆盖率、平均高度、高度方差、体积。

UTCI结果沿完整道路网络显示为绿色至红色的连续渐变。用户可按行政区浏览，也可搜索有名称的道路，查看其道路热环境和规划管理分析。

## AI模型与计算分工

### 已发表研究模型

项目团队在基础研究中建立XGBoost模型并完成SHAP分析，研究成果已发表。HeatPlan调用该研究中已有的模型结果和解释证据，为道路形态诊断提供科学依据。

### HeatPlan Agent

HeatPlan Agent使用DeepSeek API和smolagents的ToolCallingAgent框架。它读取管理者的自然语言任务，决定调用哪些数据和研究工具，并将返回结果组织成面向规划管理的解释。

Agent可执行的任务包括：识别高温问题类型、诊断指定道路位置、比较八项形态指标与改善方向、匹配相似道路、检索论文证据、比较多个地点、检索道路相关政策与改造项目，以及根据治理要求重新比较措施。

### 程序化分析工具

Python与DuckDB执行UTCI筛选、问题分类、指标提取、道路热环境统计和相似样本匹配。GeoPandas等空间处理工具用于道路关联、行政区空间查询和地图坐标转换。Streamlit提供道路热环境地图、诊断结果、措施比较和AI对话界面。

## 道路对照与规划项目检索

HeatPlan的内部参考道路来自团队自主完成的北京道路尺度研究数据。系统提供两类道路对照：

- 形态相似道路：根据八项标准化建筑与树冠指标检索整体形态相近的样本。
- 治理对照道路：优先匹配建筑形态相近、树冠配置不同的道路，并并列展示形态指标和已有模拟UTCI。

对有中文名称的目标道路，Agent还可检索道路名称相关项目、周边道路项目，以及其他地区的道路更新与绿化改造资料，重点关注2021年以来公开的城市更新、老旧街区改造、生态廊道和道路绿化项目，并给出具体措施及来源链接。

## AI数据流

DeepSeek接收使用者当前提出的任务，以及HeatPlan数据工具整理出的候选道路、形态指标摘要和论文证据，再生成任务解释与方案比较。道路数据库查询、空间筛选和样本匹配由HeatPlan应用中的程序完成。

使用者可在网页会话中提供DeepSeek API密钥；本地运行时也可从本地配置读取。API密钥不写入项目代码。
